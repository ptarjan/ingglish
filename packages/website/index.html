Ingglish
 

What if English spelling made sense?

Ingglish is phonetic English — every spelling always makes the same sound. No silent letters, no irregular pronunciations. If you can say it, you can spell it.

Examples: "enough" → "enuf" · "through" → "throo" · "knight" → "nyt" · "beautiful" → "byootiful"
