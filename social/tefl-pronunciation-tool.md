# r/TEFL or r/ESL

**Title:** Anyone use phonemic respelling with students? I made a tool for it and I'm not sure if teachers actually want this

**Body:**

I've been messing around with a side project that respells English so every letter always makes the same sound — no silent letters, no exceptions. It started because my kid kept asking why "knife" starts with a K.

I've been wondering if it'd be useful for ESL students. The idea is that you paste any text (or a URL) and it shows the pronunciation using just the 26 letters they already know, instead of making them learn IPA symbols first.

Some examples:

- colonel → kernul
- comfortable → kumftarbal
- Wednesday → Wenzday
- queue → kyuu

It's at [ingglish.com](https://ingglish.com) if you want to try it. There's also a hover mode where you only see the pronunciation when you mouse over a word, which might be less overwhelming.

Honestly not sure if this solves a real problem or if IPA is fine for most classrooms. Do any of you use phonemic respelling already? What does your pronunciation teaching actually look like day to day?
