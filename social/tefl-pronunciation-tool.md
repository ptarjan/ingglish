# r/TEFL or r/ESL

**Title:** Free tool that shows English pronunciation using only standard letters — no IPA needed

**Body:**

I keep running into the same problem teaching pronunciation: IPA is accurate but it's a whole second thing to learn, and "sounds like" descriptions are inconsistent.

So I built [ingglish.com](https://ingglish.com) — you paste any English text and it respells every word so each letter always makes the same sound. It uses standard Latin letters and digraphs like "sh" and "th" that students already recognize. Backed by the CMU Pronouncing Dictionary (134k words).

Some things it does that might be useful:

- **Paste a URL** and it translates the whole webpage in place, so students can read real articles with pronunciation guides
- **Chrome extension** that does the same thing on any site
- **Hover mode** that shows pronunciation only when you mouse over a word
- **IPA mode** if you do want IPA — toggle it in the top right

A few examples of what the output looks like:

| English | Respelled |
|---------|-----------|
| colonel | kernul |
| February | Febyuwairee |
| comfortable | kumftarbal |
| Wednesday | Wenzday |
| queue | kyuu |

It's free and open source: [github.com/ptarjan/ingglish](https://github.com/ptarjan/ingglish)

What pronunciation tools do you currently use with students? Curious if something like this would actually be useful in practice or if I'm solving a problem that doesn't exist.
